# Changelog

## 0.1 — 2026-11-12

First public desktop release, modified from [HALOFLUX by Ryder191](https://github.com/Ryder191/haloflux).

- Native macOS desktop host for the original particle, light-beam, and ring animation.
- Read-only local Orca CLI connection with model and human-request metadata enrichment.
- Up to four active/requesting workspaces, 15-second rotation, single-workspace focus.
- Original lavender plus red, blue, and green accents with smooth transitions.
- Slow standby ring and four default workspace names when there are no active tasks.
- Synchronized breathing on both barcode rings for confirmed pending human requests.
- Retina drawing, menu-bar/notch inset, English interface, adjustable motion speed.
- Automatic Orca lifecycle detection; pause rendering/polling on lock and display sleep.
- Apple Silicon ZIP installer, login startup, upgrade backups, and uninstaller.
- Chinese and English README, integration details, original license and attribution.

Desktop only. Lock-screen assets, wallpaper extensions, and screen savers are excluded. The app is ad-hoc signed and not notarized. macOS 13 is the deployment target; not every supported OS/Orca combination has been validated.
